# 🌙 صَوْمُ رَمَضَانَ — رحلة تعليمية تفاعلية (12 محطة)

تطبيق ويب تعليمي لدرس **«صوم رمضان»** (الدراسات الإسلامية – التوحيد، الصف الثالث الابتدائي، الدرس 7، ص 35–36)
لـ **مدرسة العروس الابتدائية**، مبني بـ Next.js (App Router) + Drizzle ORM + PostgreSQL (Neon).

## ✨ المميزات

- **رحلة الطالب:** 12 محطة متدرجة (بطاقات شرح، اختيار من متعدد، ترتيب كلمات الآية والحديث، سحب وإفلات لإكمال الجمل، صح/خطأ، نشاط الكتاب والتقويم) مع تعزيز صوتي ورسائل تشجيعية وشريط تقدم.
- **الشهادة:** شهادة «بطل صوم رمضان» باسم الطالب قابلة للطباعة أو التحميل PDF.
- **لوحة المعلم (`/teacher`):** إحصاءات الفصل، تحليل صعوبة المحطات، جدول الطلاب مع تفاصيل كل محاولة ومحطة، تصفية حسب الفصل، حذف طالب، تصدير CSV.
- **تقارير PDF:** تقرير الفصل (`/teacher/report`) وتقرير كل طالب (`/teacher/report/[attemptId]`) بطباعة مباشرة أو تحميل PDF.
- **ربط تلقائي بقاعدة البيانات:** تُنشأ الجداول تلقائيًا عند أول طلب (لا حاجة لأوامر ترحيل يدوية).

## 🗄️ قاعدة Neon أون لاين (مضبوطة مسبقًا)

التطبيق مربوط الآن بقاعدة Neon حقيقية عبر المتغير `NEON_DATABASE_URL` في ملف `.env`.

1. **اضغط رابط الضم (Claim)** الموجود في `.env` تحت `NEON_CLAIM_URL` لنقل القاعدة إلى حساب Neon الخاص بك (مجاني) — يجب ذلك خلال 72 ساعة من إنشائها وإلا تُحذف تلقائيًا.
2. في Vercel: **Settings → Environment Variables** أضف `NEON_DATABASE_URL` بنفس القيمة الموجودة في `.env` (أو اربط Neon من Storage ليُضاف `DATABASE_URL` تلقائيًا).
3. عند أول زيارة تُنشأ الجداول تلقائيًا. يمكنك التأكد من الاتصال عبر `/api/health` أو من مؤشر «قاعدة البيانات» أعلى لوحة المعلم.

> أولوية الاتصال: `NEON_DATABASE_URL` ← `DATABASE_URL` ← `POSTGRES_URL`. القاعدة المحلية في `.env` احتياطية للتطوير فقط.

## 🚀 النشر على Vercel مع Neon

1. ارفع المشروع إلى GitHub ثم استورده في Vercel.
2. من لوحة المشروع في Vercel: **Storage → Create Database → Neon (Postgres)** ثم **Connect Project**.
   سيضيف التكامل متغيرات البيئة تلقائيًا (`DATABASE_URL`, `POSTGRES_URL`, ...) — التطبيق يقرأها جميعًا.
3. (اختياري) أضف المتغيرات التالية من **Settings → Environment Variables**:
   - `TEACHER_PASSWORD` — لتغيير كلمة مرور لوحة المعلم (وإلا تُستخدم الكلمة المضبوطة في `src/lib/teacher-auth.ts`).
   - `TEACHER_SESSION_SECRET` — سر توقيع جلسة المعلم (اختياري).

> دخول المعلم يعتمد على رمز جلسة يُحفظ في المتصفح ويُرسل مع كل طلب، لذا يعمل حتى داخل الإطارات (iframe) التي تمنع الكوكيز.
4. اضغط **Deploy**. عند أول زيارة للموقع تُنشأ الجداول تلقائيًا في Neon.

> ملاحظة: يُفضَّل استخدام رابط الاتصال المجمّع (Pooled) من Neon على Vercel، وهو ما يضبطه التكامل افتراضيًا.

## 🧑‍💻 التشغيل محليًا

```bash
npm install
# عدّل DATABASE_URL في ملف .env إن لزم
npm run dev
```

لإنشاء الجداول يدويًا (اختياري): `npx drizzle-kit push`

## 🗂️ بنية المشروع

- `src/lib/lesson-data.ts` — محتوى الدرس والمحطات الاثنتي عشرة ونظام النقاط.
- `src/components/lesson/*` — واجهة الطالب (المحطات، الشهادة، الصوت).
- `src/components/teacher/*` — لوحة المعلم وأدوات الطباعة.
- `src/app/api/*` — واجهات حفظ المحاولات والنتائج ومصادقة المعلم والتصدير.
- `src/db/*` — مخطط Drizzle والاتصال وإنشاء الجداول التلقائي.
